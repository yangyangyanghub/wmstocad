# WMS 地图插件 - 图层配置说明

## 概述

插件通过 `shared/layers.json` 文件管理 WMS 服务和投影配置。修改此文件后，在插件中点击 "刷新配置" 即可生效，无需重启软件。

**配置文件位置：**

| 平台 | 路径 |
|------|------|
| 开发目录 | `shared/layers.json` |
| AutoCAD 安装后 | `%APPDATA%\Autodesk\ApplicationPlugins\WmsMapPlugin.bundle\Contents\shared\layers.json` |
| WPS 安装后 | `%APPDATA%\Kingsoft\wps\addons\pool\win-i386\wms-plugin\shared\layers.json` |

---

## 一、layers.json 格式

```json
{
  "services": [...],
  "defaultProjection": {...},
  "availableProjections": [...]
}
```

### 1.1 services — WMS 服务列表

每个服务代表一个可切换的图层组。

```json
{
  "services": [
    {
      "id": "dom202605y2m18level",
      "name": "DOM 2026年5月 18级",
      "url": "http://61.240.150.90:8088/mixserver/services/map-ugcv5-dom202605y2m18level/wms111/dom202605y2m18level?",
      "version": "1.1.1",
      "srs": "EPSG:4490",
      "format": "image/png",
      "bbox": {
        "minx": 113.4515533010966,
        "miny": 36.04214231457183,
        "maxx": 115.49902771933739,
        "maxy": 37.02216653756615
      },
      "layers": [
        {
          "name": "0",
          "title": "DOM 底图",
          "queryable": true
        }
      ]
    }
  ]
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 服务唯一标识，建议使用英文，不可重复 |
| `name` | string | 是 | 在图层下拉框中显示的名称 |
| `url` | string | 是 | WMS 服务地址（以 `?` 结尾） |
| `version` | string | 是 | WMS 版本，当前支持 `"1.1.1"` |
| `srs` | string | 是 | 服务坐标系，当前固定为 `"EPSG:4490"` |
| `format` | string | 是 | 出图格式，支持 `"image/png"`、`"image/jpeg"` |
| `bbox` | object | 是 | 服务地理范围（经纬度） |
| `bbox.minx` | number | 是 | 最小经度 |
| `bbox.miny` | number | 是 | 最小纬度 |
| `bbox.maxx` | number | 是 | 最大经度 |
| `bbox.maxy` | number | 是 | 最大纬度 |
| `layers` | array | 是 | 该服务下的子图层列表 |
| `layers[].name` | string | 是 | WMS 图层名称（服务端定义） |
| `layers[].title` | string | 是 | 图层显示名称 |
| `layers[].queryable` | boolean | 否 | 是否支持要素查询，默认 `false` |

### 1.2 defaultProjection — 默认投影

插件启动时使用的投影坐标系。

```json
{
  "defaultProjection": {
    "epsg": "EPSG:4534",
    "name": "CGCS2000 / 3度带 114°E",
    "proj4": "+proj=tmerc +lat_0=0 +lon_0=114 +k=1 +x_0=38500000 +y_0=0 +ellps=GRS80 +units=m +no_defs +type=crs"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `epsg` | string | EPSG 编码 |
| `name` | string | 投影名称（显示在下拉框中） |
| `proj4` | string | proj4 投影定义字符串 |

### 1.3 availableProjections — 可选投影列表

用户可在地图面板中切换的投影坐标系。

```json
{
  "availableProjections": [
    {
      "epsg": "EPSG:4490",
      "name": "CGCS2000 (经纬度)",
      "proj4": "+proj=longlat +ellps=GRS80 +no_defs +type=crs",
      "unit": "度"
    },
    {
      "epsg": "EPSG:4534",
      "name": "CGCS2000 / 3度带 114°E",
      "proj4": "+proj=tmerc +lat_0=0 +lon_0=114 +k=1 +x_0=38500000 +y_0=0 +ellps=GRS80 +units=m +no_defs +type=crs",
      "unit": "米"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `epsg` | string | EPSG 编码 |
| `name` | string | 投影名称 |
| `proj4` | string | proj4 投影定义字符串 |
| `unit` | string | 坐标单位（"度" 或 "米"） |

## 二、添加新 WMS 服务

在 `services` 数组中添加新项即可。插件会自动渲染到图层下拉框中。

### 示例：添加一个 DOM 影像服务

```json
{
  "services": [
    {
      "id": "dom202605y2m18level",
      "name": "DOM 2026年5月 18级",
      "url": "http://61.240.150.90:8088/mixserver/services/map-ugcv5-dom202605y2m18level/wms111/dom202605y2m18level?",
      "version": "1.1.1",
      "srs": "EPSG:4490",
      "format": "image/png",
      "bbox": {
        "minx": 113.4515533010966,
        "miny": 36.04214231457183,
        "maxx": 115.49902771933739,
        "maxy": 37.02216653756615
      },
      "layers": [
        {
          "name": "0",
          "title": "DOM 底图",
          "queryable": true
        }
      ]
    },
    {
      "id": "new-service-id",
      "name": "新服务名称",
      "url": "http://your-wms-server:port/path/wms?",
      "version": "1.1.1",
      "srs": "EPSG:4490",
      "format": "image/png",
      "bbox": {
        "minx": 113.0,
        "miny": 36.0,
        "maxx": 116.0,
        "maxy": 37.5
      },
      "layers": [
        {
          "name": "layer_name",
          "title": "显示名称",
          "queryable": false
        }
      ]
    }
  ]
}
```

### 获取 WMS 服务信息

1. 在浏览器中访问 WMS 服务的 GetCapabilities 地址：
   ```
   http://your-wms-server:port/path/wms?SERVICE=WMS&VERSION=1.1.1&REQUEST=GetCapabilities
   ```
2. 从返回的 XML 中获取：
   - 服务 URL
   - 图层名称（`<Name>` 标签）
   - 图层标题（`<Title>` 标签）
   - 地理范围（`<LatLonBoundingBox>` 标签）
   - 支持的坐标系和格式

## 三、添加自定义投影

在 `availableProjections` 数组中添加新项。

### 示例：添加 CGCS2000 / 3度带 111°E（EPSG:4533）

```json
{
  "availableProjections": [
    {
      "epsg": "EPSG:4490",
      "name": "CGCS2000 (经纬度)",
      "proj4": "+proj=longlat +ellps=GRS80 +no_defs +type=crs",
      "unit": "度"
    },
    {
      "epsg": "EPSG:4534",
      "name": "CGCS2000 / 3度带 114°E",
      "proj4": "+proj=tmerc +lat_0=0 +lon_0=114 +k=1 +x_0=38500000 +y_0=0 +ellps=GRS80 +units=m +no_defs +type=crs",
      "unit": "米"
    },
    {
      "epsg": "EPSG:4533",
      "name": "CGCS2000 / 3度带 111°E",
      "proj4": "+proj=tmerc +lat_0=0 +lon_0=111 +k=1 +x_0=37500000 +y_0=0 +ellps=GRS80 +units=m +no_defs +type=crs",
      "unit": "米"
    }
  ]
}
```

### proj4 参数说明

以 `+proj=tmerc`（横轴墨卡托投影）为例：

| 参数 | 说明 | 示例 |
|------|------|------|
| `+proj=tmerc` | 投影类型（横轴墨卡托） | — |
| `+lat_0=0` | 原点纬度 | 0 |
| `+lon_0=114` | 中央经线（根据所在地区选择） | 114°E |
| `+k=1` | 比例因子 | 1 |
| `+x_0=38500000` | 假东偏移（含带号，38 = 带号38 × 1000000 + 500000） | 38500000 |
| `+y_0=0` | 假北偏移 | 0 |
| `+ellps=GRS80` | 参考椭球体 | GRS80（CGCS2000 使用） |
| `+units=m` | 坐标单位 | m（米） |
| `+no_defs` | 不加载默认定义 | — |
| `+type=crs` | 类型为坐标参考系 | crs |

### 常用 CGCS2000 3度带投影

| EPSG | 中央经线 | 假东偏移 | 适用经度范围 |
|------|----------|----------|-------------|
| EPSG:4533 | 111°E | 37500000 | 109.5°-112.5° |
| EPSG:4534 | 114°E | 38500000 | 112.5°-115.5° |
| EPSG:4535 | 117°E | 39500000 | 115.5°-118.5° |
| EPSG:4536 | 120°E | 40500000 | 118.5°-121.5° |

> 选择投影时，中央经线应尽量靠近项目所在区域的中心经度，以减小投影变形。

## 四、配置刷新

修改 `layers.json` 后，无需重启软件：

| 平台 | 刷新方式 |
|------|----------|
| AutoCAD | 在地图面板中点击 **刷新配置** 按钮 |
| WPS | 在 Ribbon "WMS地图" 选项卡中点击 **刷新配置** 按钮 |

刷新后，插件会重新读取配置文件，更新图层列表和投影选项。

---

## 五、配置校验

修改 `layers.json` 时注意：

1. **JSON 格式必须正确** — 使用 JSON 编辑器或在线校验工具检查语法
2. **id 不可重复** — 每个服务的 `id` 必须唯一
3. **URL 必须以 `?` 结尾** — WMS 服务地址末尾需要带问号
4. **bbox 范围正确** — `minx < maxx`，`miny < maxy`
5. **proj4 字符串完整** — 确保包含所有必要参数
6. **编码为 UTF-8** — 中文名称需要 UTF-8 编码保存

### 常见错误

| 错误 | 现象 | 解决 |
|------|------|------|
| JSON 语法错误（缺少逗号、引号） | 插件提示 "layers.json 格式错误" | 用 JSON 编辑器校验 |
| URL 缺少末尾 `?` | WMS 请求拼接错误，地图无法加载 | 在 URL 末尾添加 `?` |
| EPSG 编码拼写错误 | 投影切换失败 | 检查 `epsg` 字段格式为 `"EPSG:XXXX"` |
| proj4 参数缺失 | 坐标转换结果异常 | 参考 epsg.io 查询完整 proj4 定义 |
