# WMS 地图插件 - 用户手册

## 概述

WMS 地图插件为 AutoCAD 和 WPS PPT 提供可交互地图功能，支持：

- 浏览 WMS 地图服务（缩放、平移）
- 切换不同图层
- 切换投影坐标系（5 个预定义投影 + 自定义）
- 将地图插入到 CAD 图纸或 PPT 幻灯片中

---

## 一、AutoCAD 使用方法

### 1.1 打开地图面板

1. 启动 AutoCAD
2. 在命令行输入 `WMSMAP`，按回车
3. 右侧出现地图面板，自动加载地图

> 面板支持拖拽停靠到左侧或右侧，也可浮动使用。

### 1.2 图层选择

1. 在地图面板的 **图层** 区域，点击下拉框
2. 选择需要的图层（如 "DOM 底图"）
3. 地图自动切换到所选图层

> 图层列表来自 `shared/layers.json` 配置文件。如果管理员新增了图层，点击 **刷新配置** 按钮即可更新列表。

### 1.3 投影切换

1. 在地图面板的 **投影** 区域，点击下拉框
2. 选择目标投影坐标系：
   - **CGCS2000 (经纬度)** — EPSG:4490，单位为度
   - **CGCS2000 / 3度带 114°E** — EPSG:4534，单位为米（默认）
   - **CGCS2000 / 3度带 117°E** — EPSG:4535，单位为米
   - **CGCS2000 / 3度带 120°E** — EPSG:4536，单位为米
   - **Web 墨卡托** — EPSG:3857，单位为米
   - **自定义...** — 输入自定义 proj4 字符串
3. 选择 "自定义..." 时，在下方输入框中填入 proj4 定义，地图自动切换

> 投影切换不会改变 WMS 服务端的坐标系，而是在前端进行坐标转换，使地图显示在目标投影下。

### 1.4 地图浏览

- **缩放**：鼠标滚轮上下滚动
- **平移**：按住鼠标左键拖动
- **定位到服务范围**：双击地图或点击面板中的定位按钮

### 1.5 插入地图到 CAD

插件提供两种出图方式：

#### GetMap 出图（推荐）

1. 在地图面板中调整好视图（图层、投影、缩放级别、范围）
2. 点击 **GetMap 出图（高质量）** 按钮
3. 插件根据当前视图范围向 WMS 服务端请求高分辨率图片
4. 图片自动插入到 CAD 当前图纸中，位置和比例与当前视图一致

> GetMap 出图质量高，不受屏幕分辨率影响，适合正式出图。

#### 快速截图

1. 在地图面板中调整好视图
2. 点击 **快速截图** 按钮
3. 插件截取当前屏幕显示的地图画面
4. 截图插入到 CAD 当前图纸中

> 快速截图速度快，但分辨率受屏幕限制，适合快速预览。

#### 插入地图按钮

点击 **插入地图到 CAD** 按钮，效果等同于 GetMap 出图。

## 二、WPS PPT 使用方法

### 2.1 打开地图面板

1. 打开 WPS 演示（PPT）
2. 点击 Ribbon 菜单栏的 **"WMS地图"** 选项卡
3. 点击 **打开地图** 按钮
4. 右侧出现地图任务窗格，自动加载地图

### 2.2 图层选择

1. 在地图面板的 **图层** 区域，点击下拉框
2. 选择需要的图层
3. 地图自动切换

> 如果修改了 `shared/layers.json`，点击 Ribbon 上的 **刷新配置** 按钮更新图层列表。

### 2.3 投影切换

1. 在地图面板的 **投影** 区域，点击下拉框
2. 选择目标投影坐标系（同 AutoCAD 的 5 个预定义投影 + 自定义）
3. 地图自动切换到目标投影

### 2.4 地图浏览

- **缩放**：鼠标滚轮或触摸板双指缩放
- **平移**：鼠标拖动或触摸板双指滑动

### 2.5 插入地图到 PPT

1. 在地图面板中调整好视图（图层、投影、缩放级别、范围）
2. 点击 Ribbon 上的 **插入地图** 按钮
3. 插件自动截取当前地图视图
4. 图片插入到当前幻灯片，自动居中并保持宽高比

> 如果未打开地图面板就点击 "插入地图"，会提示 "请先打开地图"。

## 三、常见问题解答（FAQ）

### Q1: 地图面板打开后一片空白？

**可能原因：**
- 网络不通，无法访问 WMS 服务
- WebView2 Runtime 未安装（AutoCAD）
- WPS 版本过低

**解决方法：**
1. 确认电脑处于院内网络环境
2. 用浏览器访问 `layers.json` 中的 WMS 服务地址，确认能返回图片
3. AutoCAD 用户检查 WebView2 Runtime 是否已安装
4. 查看日志文件获取详细错误信息

### Q2: 图层下拉框为空？

**可能原因：**
- `layers.json` 文件缺失或格式错误
- 配置文件路径不正确

**解决方法：**
1. 检查 `shared/layers.json` 文件是否存在
2. 用文本编辑器打开，确认 JSON 格式正确
3. 点击 "刷新配置" 按钮重新加载

### Q3: 切换投影后地图显示异常？

**可能原因：**
- 自定义 proj4 参数有误
- 投影范围超出 WMS 服务范围

**解决方法：**
1. 检查 proj4 字符串是否正确
2. 切换到默认投影（EPSG:4534）确认是否正常
3. 确保自定义投影的范围与 WMS 服务范围有交集

### Q4: 插入地图失败或图片模糊？

**可能原因：**
- GetMap 出图：WMS 服务不可访问
- 快速截图：屏幕分辨率低或跨域限制

**解决方法：**
1. 优先使用 GetMap 出图，质量更高
2. 检查网络连接
3. 如果截图失败，插件会自动尝试 GetMap 方式

### Q5: AutoCAD 中 WMSMAP 命令无响应？

**可能原因：**
- 插件未正确加载
- 面板已在后台运行

**解决方法：**
1. 检查 AutoCAD 命令行是否有 `[WMS]` 开头的加载提示
2. 如果没有提示，检查插件是否安装正确（参考安装说明）
3. 如果面板已打开但不可见，再次输入 WMSMAP 会激活已有面板

### Q6: WPS 中 "插入地图" 按钮灰色不可用？

**原因：** 地图面板未打开。

**解决方法：** 先点击 "打开地图" 按钮，打开地图面板后 "插入地图" 按钮自动变为可用。

### Q7: 如何查看日志？

| 平台 | 日志路径 |
|------|----------|
| AutoCAD | `WmsMapPlugin.bundle/Contents/logs/autocad-plugin.log` |
| WPS | `wps/wps-plugin.log` |

日志记录插件启动、图层加载、投影切换、出图操作和错误信息，排查问题时可提供给技术支持。

### Q8: 地图面板能否同时打开多个？

不能。AutoCAD 和 WPS 中地图面板均为单例模式，多次执行打开操作只会激活已有面板。

### Q9: 支持哪些 WMS 版本？

当前支持 WMS 1.1.1 版本。如果服务使用 WMS 1.3.0，需要在 `layers.json` 中修改 `version` 字段，但需确认服务端兼容性。

### Q10: 地图数据是否会缓存？

第一版不做本地缓存，每次浏览和出图都实时请求 WMS 服务。后续版本可能增加缓存功能。
