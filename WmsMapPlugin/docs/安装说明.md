# WMS 地图插件 - 安装说明

## 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 或更高版本 |
| AutoCAD | 2021 或更高版本（如需 CAD 插件） |
| WPS Office | 2019 或更高版本（如需 PPT 插件） |
| WebView2 Runtime | 系统需安装 Microsoft Edge WebView2 Runtime |
| 网络 | 需能访问 WMS 地图服务地址（院内网络） |

> WebView2 Runtime 通常随 Windows 更新自动安装。如果插件启动后地图面板空白，请前往 [微软官网](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 下载安装。

## 一、AutoCAD 插件安装

### 方法一：脚本安装（推荐）

1. 关闭 AutoCAD
2. 右键点击 `install-autocad.ps1`，选择 **使用 PowerShell 运行**
   - 或在 PowerShell 终端中执行：
     ```powershell
     .\install-autocad.ps1
     ```
3. 脚本会自动完成以下操作：
   - 将 `WmsMapPlugin.bundle` 复制到 AutoCAD 插件目录
   - 将 `shared/` 目录（含地图页面和图层配置）复制到插件目录
4. 看到 "安装完成!" 提示后，启动 AutoCAD

> 如果系统未安装 PowerShell 7+，可双击运行 `install-autocad.bat`，它会自动调用 PowerShell。

### 方法二：手动安装

1. 关闭 AutoCAD
2. 找到 AutoCAD 插件目录：
   ```
   %APPDATA%\Autodesk\ApplicationPlugins\
   ```
   （即 `C:\Users\<用户名>\AppData\Roaming\Autodesk\ApplicationPlugins\`）
3. 将 `autocad/WmsMapPlugin.bundle` 整个目录复制到上述路径
4. 将 `shared/` 目录复制到 `WmsMapPlugin.bundle/Contents/` 下
5. 最终目录结构：
   ```
   %APPDATA%\Autodesk\ApplicationPlugins\
   └── WmsMapPlugin.bundle\
       ├── PackageContents.xml
       └── Contents\
           ├── WmsMapPlugin.dll
           └── shared\
               ├── map.html
               ├── layers.json
               ├── css\
               ├── js\
               └── lib\
   ```
6. 启动 AutoCAD

### 验证安装

1. 启动 AutoCAD
2. 命令行应显示提示：`[WMS] 插件已加载，输入 WMSMAP 打开地图面板`
3. 在命令行输入 `WMSMAP` 并回车
4. 右侧应出现地图面板，显示可交互地图

## 二、WPS 插件安装

详细安装步骤请参考 [WPS 安装说明](wps-install.md)。

以下为简要步骤：

### 1. 放置插件目录

将 `wms-plugin` 目录（包含 `wps/` 和 `shared/`）复制到：

```
%APPDATA%\Kingsoft\wps\addons\pool\win-i386\wms-plugin\
```

或通过 WPS 开发工具加载：

1. 打开 WPS 演示（PPT）
2. 点击 **开发工具** → **WPS 加载项**（或 **JSAPI 调试**）
3. 点击 **添加本地项目**
4. 选择 `wps/manifest.xml` 文件
5. 确认加载

### 2. 验证安装

安装成功后，WPS PPT 的 Ribbon 菜单栏会出现 **"WMS地图"** 选项卡，包含以下按钮：

| 按钮 | 功能 |
|------|------|
| 打开地图 | 在右侧打开可交互地图面板 |
| 插入地图 | 将当前地图视图插入到幻灯片 |
| 刷新配置 | 重新加载图层配置文件 |
| 关于 | 查看插件版本和兼容性信息 |

## 三、卸载

### AutoCAD 插件卸载

**方法一：脚本卸载**

```powershell
.\install-autocad.ps1 -Uninstall
```

**方法二：手动卸载**

删除以下目录：

```
%APPDATA%\Autodesk\ApplicationPlugins\WmsMapPlugin.bundle\
```

### WPS 插件卸载

**方法一：通过 WPS 卸载**

1. 打开 WPS 演示
2. 点击 **开发工具** → **WPS 加载项**
3. 找到 "WMS 地图插件"
4. 点击 **删除**

**方法二：手动卸载**

删除以下目录：

```
%APPDATA%\Kingsoft\wps\addons\pool\win-i386\wms-plugin\
```

## 四、常见问题

### Q: AutoCAD 启动后没有 WMS 提示？

- 检查 `WmsMapPlugin.bundle` 是否在 `%APPDATA%\Autodesk\ApplicationPlugins\` 目录下
- 检查 AutoCAD 版本是否 >= 2021
- 查看日志文件：`WmsMapPlugin.bundle/Contents/logs/autocad-plugin.log`

### Q: 地图面板显示空白或加载失败？

- 检查 WebView2 Runtime 是否已安装
- 检查网络是否能访问 WMS 服务地址（`shared/layers.json` 中配置的 URL）
- 在 AutoCAD 命令行查看是否有错误提示

### Q: WPS Ribbon 没有出现 "WMS地图" 选项卡？

- 检查 `manifest.xml` 中的 `<platform>` 是否为 `wps`
- 检查 WPS 版本是否 >= 2019
- 查看 `wps/wps-plugin.log` 中的错误信息

### Q: 地图无法显示或图层加载失败？

- 确认电脑处于院内网络环境，能访问 WMS 服务地址
- 用浏览器直接访问 `layers.json` 中的 WMS URL，确认服务可用
- 在地图面板中点击 "刷新配置" 重新加载配置

### Q: 安装脚本执行报错？

- 确保以当前用户身份运行（不需要管理员权限）
- 检查 PowerShell 执行策略：如受限，可在 PowerShell 中执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
- 或直接用 `install-autocad.bat` 运行，它会自动绕过执行策略
