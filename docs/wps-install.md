# WMS 地图插件 - WPS 安装说明

## 环境要求

| 项目 | 要求 |
|------|------|
| WPS Office | 2019 或更高版本 |
| 操作系统 | Windows 7/10/11 |
| 网络 | 需能访问 WMS 地图服务地址 |

> 插件启动时会自动检测 WPS 版本，低于 2019 版本将显示兼容性警告。

## 安装步骤

### 1. 获取插件文件

确保以下目录结构完整：

```
wms-plugin/
├── wps/
│   ├── manifest.xml        # 插件清单
│   ├── ribbon.xml          # Ribbon 界面定义
│   ├── taskpane.html       # 任务窗格页面
│   ├── js/
│   │   └── main.js         # 主逻辑
│   └── icons/              # 按钮图标（可选）
│       ├── open-map.png
│       ├── insert-map.png
│       └── refresh.png
└── shared/
    ├── layers.json         # 图层配置
    └── map.html            # 地图页面
```

### 2. 放置插件目录

将整个 `wms-plugin` 目录复制到 WPS 插件目录：

```
%APPDATA%\Kingsoft\wps\addons\pool\win-i386\wms-plugin\
```

或通过 WPS 开发工具加载：

1. 打开 WPS 演示（PPT）
2. 点击 **开发工具** → **WPS 加载项** （或 **JSAPI 调试**）
3. 点击 **添加本地项目**
4. 选择 `wps/manifest.xml` 文件
5. 确认加载

### 3. 验证安装

安装成功后，WPS PPT 的 Ribbon 菜单栏会出现 **"WMS地图"** 选项卡，包含以下按钮：

| 按钮 | 功能 |
|------|------|
| 打开地图 | 在右侧打开可交互地图面板 |
| 插入地图 | 将当前地图视图插入到幻灯片 |
| 刷新配置 | 重新加载图层配置文件 |
| 关于 | 查看插件版本和兼容性信息 |

### 4. 配置图标（可选）

Ribbon 按钮默认使用 `image` 属性引用 `icons/` 目录下的本地图标。如果图标文件缺失，按钮将不显示图标。

解决方案：
- 将 32x32（大按钮）或 16x16（小按钮）的 PNG 图标放入 `wps/icons/` 目录
- 或修改 `ribbon.xml`，将 `image="icons/xxx.png"` 替换为 `imageMso="内置图标名"`

## 使用说明

1. **打开地图**：点击 "打开地图" 按钮，右侧出现地图面板
2. **浏览地图**：在面板中切换图层、调整投影、缩放浏览
3. **插入地图**：调整好地图视图后，点击 "插入地图" 将截图插入当前幻灯片
4. **刷新配置**：修改 `shared/layers.json` 后，点击 "刷新配置" 使更改生效

## 日志

插件运行日志写入 `wps/wps-plugin.log`，记录以下事件：

- 插件启动/关闭
- WPS 版本检测结果
- 图层配置加载/刷新
- 地图图片插入
- 错误和警告信息

## 卸载步骤

### 方法一：通过 WPS 卸载

1. 打开 WPS 演示
2. 点击 **开发工具** → **WPS 加载项**
3. 找到 "WMS 地图插件"
4. 点击 **删除**

### 方法二：手动卸载

删除插件目录：

```
%APPDATA%\Kingsoft\wps\addons\pool\win-i386\wms-plugin\
```

## 常见问题

**Q: Ribbon 没有出现 "WMS地图" 选项卡？**
- 检查 manifest.xml 中的 `<platform>` 是否为 `wps`
- 检查 WPS 版本是否 >= 2019
- 查看 `wps-plugin.log` 中的错误信息

**Q: 点击 "插入地图" 提示 "请先打开地图"？**
- 需先点击 "打开地图" 打开任务窗格，再执行插入操作

**Q: 地图面板显示空白？**
- 检查网络是否能访问 `shared/layers.json` 中配置的 WMS 服务地址
- 检查浏览器控制台（F12）是否有错误信息
