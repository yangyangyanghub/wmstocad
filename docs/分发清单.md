# WMS 地图插件 - 分发清单

## 最小分发文件

分发给其他人使用时，只需要以下 **3 个部分**：

```
├── 一键安装.bat                          ← 安装脚本
├── 一键卸载.bat                          ← 卸载脚本（可选）
└── WmsMapPlugin/
    ├── autocad/
    │   └── WmsMapPlugin.bundle/          ← 核心插件包
    │       ├── PackageContents.xml
    │       └── Contents/
    │           ├── WmsMapPlugin.dll
    │           ├── Microsoft.Web.WebView2.Core.dll
    │           ├── Microsoft.Web.WebView2.WinForms.dll
    │           └── WebView2Loader.dll
    └── shared/                           ← 前端代码
        ├── map.html
        ├── layers.json
        ├── css/
        ├── js/
        └── lib/
```

## 文件大小估算

| 部分 | 大小 |
|------|------|
| 核心 DLL + WebView2 | ~900 KB |
| 前端代码 (shared/) | ~1.5 MB |
| **总计** | **~2.4 MB** |

## 安装步骤

1. 把上面的文件打包成 ZIP 发给用户
2. 用户解压到任意目录
3. 双击 `一键安装.bat`
4. 启动 AutoCAD → 输入 `WMSMAP` 回车

## 不需要分发的文件

以下文件是开发/构建产物，**不需要**包含在分发包里：

- `autocad/bin/` - 编译中间文件
- `autocad/obj/` - 编译中间文件
- `autocad/*.cs` - 源代码
- `shared/js/*.js` 的 `.map` 文件（如果有）
- `docs/` - 开发文档
- `poc/` - 验证代码
- `install-autocad.ps1` - 旧版安装脚本
- `sync-delivery.ps1` - 开发用同步脚本
- `.git/` - 版本控制
- `.omo/` - 开发工具

## 打包命令示例

```powershell
# 在项目根目录执行
$files = @(
    "一键安装.bat",
    "一键卸载.bat",
    "WmsMapPlugin\autocad\WmsMapPlugin.bundle",
    "WmsMapPlugin\shared"
)

Compress-Archive -Path $files -DestinationPath "WMS地图插件-v1.0.0.zip" -Force
```

## 环境要求

- **AutoCAD 2021+**（需要 .NET Framework 4.8）
- **WebView2 Runtime**（Windows 10/11 通常已预装）
- Windows 7/8/10/11

## 验证安装

安装后检查：

```
%APPDATA%\Autodesk\ApplicationPlugins\WmsMapPlugin.bundle\
├── PackageContents.xml
└── Contents\
    ├── WmsMapPlugin.dll
    ├── Microsoft.Web.WebView2.Core.dll
    ├── Microsoft.Web.WebView2.WinForms.dll
    ├── WebView2Loader.dll
    └── shared\
        ├── map.html
        ├── layers.json
        ├── css\
        ├── js\
        └── lib\
```

如果 `shared/` 目录存在且包含 `map.html`，说明安装成功。
